# Aashiyana

**A private, self-hosted household planner.**

Project name: **Aashiyana**  
Customized by: **Ayush Chandrawat**

## Features

- Household calendar and tasks
- Shopping and meal planning
- Budget and notes
- Contacts and documents
- Self-hosted SQLite storage
- PWA support

## Setup

1. Copy `.env.example` to `.env`.
2. Set a strong `SESSION_SECRET`.
3. Set `DB_ENCRYPTION_KEY` if database encryption is desired.
4. Install dependencies with `npm install`.
5. Start with `npm start`.

For Docker/Podman deployment, see the compose files included in this project.
