Advanced Settings

Single sign-on, access to your home network, and a few fine adjustments. All optional.

Single sign-on

Fill in all four fields to enable SSO, or leave them empty.

Only enable this if your provider does not send email_verified and you trust it.
Turn this off when your provider serves more people than this household. Existing accounts still sign in and still get linked.
Turning this off makes SSO the only way in: the login form and password reset disappear. It takes effect once at least one account is linked to your provider, so a fresh install can still create its first admin. If your provider becomes unreachable, the way back is editing the .env file and restarting.
Access to your home network

Aashiyana refuses connections to addresses on your own network by default, which protects against a server being tricked into reaching internal services. Enable what you actually run at home.
